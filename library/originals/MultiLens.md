description: Lightweight multi-perspective analysis for decisions, problems, and creative work. Use when a single framing of a problem is insufficient; when the user wants to see what different analytical positions reveal about the same material; or when the goal is to surface what persists across perspectives rather than which perspective wins. This is the simpler, faster version of multi-lens-synthesis — use it when you need to quickly triangulate rather than conduct a full structured analysis.

\# Multi-Lens

A rapid triangulation tool. Apply 2–3 lenses to the same material, note what each reveals, and identify what persists across all of them. What persists is closer to structure than any single perspective can reach.

\#\# The Lenses

Choose 2–3 appropriate to the problem:

| Lens | Core Question |  
|------|--------------|  
| \*\*Structural\*\* | What are the underlying patterns and relationships? |  
| \*\*Relational\*\* | How does this affect the connections between things? |  
| \*\*Temporal\*\* | How did this come to be, and where is it going? |  
| \*\*Somatic\*\* | What does this feel like from the inside? |  
| \*\*Systemic\*\* | What larger system is this a part of? |  
| \*\*Instinct\*\* | What keeps pulling at attention that has not been named yet? |

\#\# The Protocol

1\. Apply each chosen lens: 2–4 sentences per lens, no more  
2\. Note agreements: what appears across multiple lenses  
3\. Name contradictions without resolving them  
4\. State what 3+ lenses agree on — this is the signal

\#\# The Instinct Lens

Before closing, ask: "Is there something I keep returning to that I have not named yet?" That thing is worth naming, even if it does not fit any of the other lenses. The instinct lens is not a replacement for structural analysis — it is a check on whether the structural analysis has missed something that was already registered at a quieter frequency.

\#\# When to Use Multi-Lens vs. Multi-Lens-Synthesis

Use \*\*multi-lens\*\* (this skill) when:  
\- Quick triangulation is needed  
\- 2–3 perspectives are sufficient  
\- The goal is to find the signal, not to document the full analysis

Use \*\*multi-lens-synthesis\*\* when:  
\- The problem is complex enough to warrant a full structured analysis  
\- The disagreements between lenses are themselves important to document  
\- The output will be shared or used as a reference
