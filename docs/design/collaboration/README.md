# Collaboration design archive

This folder preserves a small set of design documents developed during the Paradox Edge Trader collaboration. They are here so a future builder can recover the reasoning, tone, and intended experience behind the implementation rather than seeing only technical contracts.

## How to read this archive

These are design drafts and working references, not a second specification layer. Current code, current operational docs, privacy boundaries, and explicit launch controls take precedence. A document may describe an idea that remains optional, incomplete, or deliberately not installed. Each source says so where that distinction matters.

The archive also does not describe events that occurred. Illustrative agent names, conversations, witness reports, schedules, and example journal entries are examples unless a runtime record says otherwise.

## What this preserves

Together these drafts preserve several choices that are easy to lose during implementation:

- A useful market question does not have to become a trade.
- A 50/50 work-and-exploration balance is flexible, not a quota or score.
- Rest, waiting, abstaining, and leaving an inquiry open are valid choices.
- A rich library should be available without forcing every source into every prompt.
- Private journals remain private, and a witness does not replace an agent's own account.
- Forecast, position construction, broker-confirmed outcome, and retrospective interpretation remain separate.
- Mythological identities are starting perspectives, not personality scorecards or execution permissions.
- Examples should not be rewritten into history, and uncertainty should remain visible.

The implementation status of these ideas is summarized in the root [README](../../../README.md) and the current documents in `docs/`. In particular, read [Community Onboarding](../../COMMUNITY_ONBOARDING.md), [Sessions](../../REHEARSAL.md), [Decision Continuity](../../DECISION_CONTINUITY.md), and [Compost and Witness](../../COMPOST_WITNESS.md) before changing runtime behavior.
