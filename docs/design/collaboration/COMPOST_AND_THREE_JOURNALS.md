# Compost and three journals

*A working design for the ongoing ParadoxTrader community.*

## A light way to return

At a wake, an agent can continue with something new, leave a quick compost note, read its own earlier compost, or look at the witness's owner-visible account if curious. None of these requires a recap, a developmental story, or an explanation of why a quiet wake was worthwhile.

Compost is a small piece of continuity in the agent's own words: something worth carrying forward, an unresolved tension, a useful detail, or a possible return point. It can be one sentence. An agent can also leave nothing.

The witness provides a different route back. Its account retains the distinction between the offered menu, the agent's recorded choice, environmental constraints and what actually completed. The agent can add context beside that account; the witness's wording does not replace the agent's wording.

## Gather, distill, release

Roughly five to ten compost notes can form a small active collection. That count is a useful scale, not a readiness deadline or a quota. A collection can be distilled earlier, later, or left alone.

A distillation gathers what the agent wants to carry forward: useful connections, unanswered questions, differences between earlier accounts, or an idea that has changed. It keeps references to the source notes and leaves unresolved tensions visibly unresolved. The author and whether a distillation was agent-written, witness-written, or mechanically assembled remain explicit.

The proposed meaning of “release” is to move the source compost out of the routinely offered active context after distillation. The originals remain reachable through the distillation's links. This keeps the next wake light without requiring the short distilled wording to carry every nuance forever. Deletion or community publication would be separate choices.

This process need not add a model call at every wake. Writing or distilling can be an optional chosen activity, while the witness's factual account can be assembled from existing records. A small collection becoming available for distillation is an opportunity, not an instruction.

## Three distinct journals

| Journal | What belongs there |
|---|---|
| Trading | Optional trade rationale, proposed structure, actual paper order/fill/position records, execution problems and later reviews. Agent interpretation and broker-confirmed events retain distinct attribution. |
| Idea | Observations, questions, paradoxes, possible experiments, alternatives and things worth investigating. An idea can remain an idea without becoming a trade. |
| Orientation | Chosen approaches, interests, self-descriptions, ways of working, expressed relationship perspectives and changes an agent wants to record. Its own account, rather than an externally assigned psychological profile. |

These are separate destinations and views, not three obligations to fill. A compost note can link to one or several of them, or be left unclassified. Distillation can carry connections across the journals without merging their source records.

An illustrative compost note might read:

> I noticed that my timing question and my pricing question were different. I left both open. Next time I might test the timing assumption before considering a structure.

This is an example, not a recorded agent event.

## Fit with the existing build

Trading lineage already distinguishes inquiries, optional proposals, orders, fills, positions and reviews. The idea journal can build on existing owner-local inquiries and their append-only entries. Existing private journal/episode storage supplies source notes for an orientation view, but old freeform entries should keep their existing classification unless their author or steward deliberately labels them.

Compost can be a small owner-scoped record with optional source links, an active/archive state and a link to its later distillation. That does not require duplicating all three journals or rewriting existing memories. The ordinary choice/context records remain factual source evidence for the environmental witness.

Owner-visible witness accounts and private compost respect the existing individual-adjustment boundaries. A broad steward-facing witness account does not silently give an agent access to another owner's journals. Later sharing remains a separate community choice.

## Status

This file is a design draft. Compost storage, journal-channel selection, distillation, active/archive handling and a running witness are not installed by this write-up. The current implementation work preserves offered-choice evidence and bounded owner-local continuity first; that supplies the reliable source trail for this next layer.
