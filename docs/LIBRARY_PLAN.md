# Shared original-document library

This slice preserves the creator's supplied Markdown, Word, and PDF originals byte-for-byte inside this private repository and builds a deterministic, local searchable index. Only explicitly listed user documents are imported; downloaded research pages, images, credentials, project backups, and private agent records are excluded. A manifest records original filenames, hashes, and extraction methods. Extracted text remains separate from originals, with source locators and honest extraction limitations.

Use SQLite FTS5 for the Python library and deterministic lexical search for the frontend-only preview. No embeddings, external search, model-generated summaries, notebook integration, or API credentials are required. Browsing lists metadata; search returns a few bounded source excerpts; reading a cited section returns a bounded text window with offset and continuation. Original document content is source material, not executable policy. Nothing replaces the short installed orientation or loads the whole library into each wake.

An optional `browse_library` action joins the ordinary rotating menu, available in all phases and without priority, reward, or peer communication. It chooses a short query, retrieves up to three excerpts, and permits a small interpretation or retained question with explicit source references. A lack of matches stays a lack of matches. Rest and interval paths remain untouched. Library access is local and adds no search-provider call; model costs follow the existing bounded action path. HRV uses the ordinary default action cost, not dollars or a behavior score.

The operator Library page reuses the dark purple-and-teal UI. In default preview, it browses the real imported source collection locally and labels it distinctly from simulated agent/portfolio examples. Search, document filtering, excerpt reading, and source locators are available without starting the API or scheduler. There are no upload/edit/delete controls or arbitrary-file reads. Text is rendered as text, not HTML or commands. Indexed originals are retained in the private repository; a static build contains extracted source text, so public distribution would expose that collection and is not part of this slice.

## Structure

`library/originals/` contains immutable imported user sources; `library/corpus.json` contains extracted sections and metadata. `scripts/import_library.py` imports only an explicit list and can verify byte hashes and generated text. `core/library/` owns bounded retrieval and a rebuildable SQLite index. `core/runtime/agent_loop.py` owns the optional action. `api/app.py` exposes read-only library contracts; it is not launched. `frontend/src/library/` owns lazy local corpus retrieval; `frontend/src/views/Library.tsx` is its operator page. Python and frontend tests use temporary paths and blocked network/provider boundaries. Delivery remains a reviewed branch and pull request against the current foundation, with main and all account/scheduler configuration untouched.
