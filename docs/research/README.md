# Project research notes

This folder contains research papers and evaluation notes written to support the Paradox Edge Trader build. They are not trading instructions, performance claims, or permission to connect a broker.

- [From Paradox to Evidence](ParadoxEdgeTrader_Evaluation_Protocol.md) proposes a practical protocol for evaluating paradox-driven options inquiries without collapsing forecasts, payoff, execution, costs, and hindsight into one score. It is a design paper, not an empirical result.

The current implementation and launch state remain authoritative in the root [README](../../README.md), [idea-lineage documentation](../IDEA_LINEAGE.md), and [operating-cost documentation](../OPERATING_COSTS.md).
